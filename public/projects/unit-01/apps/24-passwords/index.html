    Entropy is how many coin-flips of randomness the value holds: each extra bit doubles the guesses needed. The crack time assumes an attacker trying 10 billion guesses a second against a stolen, fast-hashed file, and counts the average (half the space). Real sites usually hash slowly, so this is a worst case.
